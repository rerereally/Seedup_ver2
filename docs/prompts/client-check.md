# 클라이언트별 실제 연결 확인 순서 (클라이언트 호환 ②)

사람이 직접 하는 확인입니다. 계획은 [supervisor-plan.md](../supervisor-plan.md) 5절 "클라이언트 호환과 실제 연결 확인" ②, 기준은 3-2의 "작동" 다섯 가지입니다. "실제 프로젝트 3개" 게이트의 첫 번째(운영 확인)를 겸합니다.

- 담당: 장차희(Claude Code, Codex), 정지훈(Antigravity)
- 시작 조건: [status.md](../status.md) 2-1 운영 준비 완료(운영 DB `verifications`, `VERIFIER_MODELS`, OpenRouter 설정)
- 결과: `docs/research/<날짜>-client-check.md`에 아래 표를 클라이언트마다 채워 계획 세션에 전달(계획 세션이 묶음 PR로 커밋)

## 준비 (한 번)

1. 공개 GitHub 테스트 저장소 하나(예: 개인 계정의 `seedup-check`). 비밀값 없이 작은 웹 앱 하나면 충분.
2. seedup.rerereally.com에서 작은 아이디어로 PRD를 만들고 목표를 잠금(성공 기준 2개). 에이전트 단계의 프로젝트 키(`prd:<id>`)를 적어 둠.
3. `/agents`에서 해당 클라이언트로 MCP 연결(토큰은 시작 문장 · 저장소 파일에 넣지 않음).
4. 에이전트 단계에서 `AGENTS.md`와 스타터 팩을 받아 테스트 저장소에 넣음(Claude Code는 `CLAUDE.md`도). Codex는 `/hooks`에서 훅을 신뢰.
