## 평가 결과 보관

- 원본 JSON과 표 또는 마크다운 요약을 `eval-results/` 아래에 같은 이름으로 보관합니다. 파일명에 실행 날짜와 조건을 적습니다. 감사 비교에는 예를 들어 `2026-11-20-audit-on.json`과 `2026-11-20-audit-off.json`을 씁니다.
- 다음에도 비교할 수 있도록 실행 시각, 스냅샷 또는 커밋, 사용한 작성·감사·채점 모델과 플래그를 남깁니다. 기존 결과는 보존합니다.
- `scripts/compare-eval.ts`는 같은 케이스의 감사 켬/끔 JSON을 비교합니다. 이전 파일에 항목별 감사 기록이 없으면 대시로 표시합니다. `scripts/eval-rivals.ts`의 실패 수는 리포트 생성 전체가 실패한 건수입니다. 후보 0건은 별도로 확인할 수 있습니다.
