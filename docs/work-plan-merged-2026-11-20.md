## 2. 먼저 정한 것

- **핵심 대상:** AI 도구나 개발 도구를 만드는 바이브코더와 사이드 프로젝트 개발자입니다. 입문 개발자, 일반 스타트업, 기업은 버리지 않고 뒤로 미룹니다. 인터뷰로 확인하기 전까지는 가정입니다. [대상]
- **중심 흐름:** 원문 → PRD → MCP. 나머지 기능은 이 흐름을 돕는지로 판단합니다. [AI][대상][수정]
- **AI 원칙:** [AI]
  - 에이전트는 찾아 오고, 채택은 코드가 합니다(`isVerbatimQuote`와 관련성 판정).
  - 판정, 점수, 증언 채택은 규칙으로 합니다.
  - 에이전트에는 단계와 시간 상한을 두고, 실패하면 지금 결과로 돌아갑니다.
  - 같은 20건으로 비교해서 이길 때만 켭니다.
  - 판정 모델은 작성 모델과 다른 회사 모델로 씁니다.
- **결제는 아직 만들지 않습니다.** 무엇에 돈을 낼지는 인터뷰와 가격을 붙인 대기 신청으로 먼저 확인합니다. [대상][AI]
