# Seedup 원문 담기 (크롬 확장)

GitHub 이슈, Hacker News, Stack Overflow 같은 글에서 문장을 고르고 오른쪽 클릭 메뉴의 **Seedup에 원문으로 담기**를 누르면, Seedup이 그 글을 직접 읽어 문장이 글자 그대로 있는지 확인한 뒤 보관합니다. 담은 문장은 PRD 작업 공간의 근거 패널 '확장으로 담은 원문'에 나옵니다.

## 설치 (개발자 모드)
1. 크롬에서 `chrome://extensions`를 엽니다.
2. 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누르고 이 `extension` 폴더를 고릅니다.
4. 확장 아이콘을 눌러 Seedup 개인 토큰(MCP 연동 화면 `/agents` > 직접 설정하기)을 넣고 저장합니다.

## 지키는 것
- 고른 문장과 그 글 주소만 Seedup으로 보냅니다. 다른 곳으로는 보내지 않습니다.
- 토큰은 브라우저의 확장 저장소에만 둡니다.
- 하루 60개까지 담을 수 있습니다.
